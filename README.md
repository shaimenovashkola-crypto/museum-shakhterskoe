# Музей села Шахтёрское

Интерактивная карта, работающая на GitHub Pages.

## Публикация
1. Загрузите `index.html`, `museum-data.json` и `README.md` в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Дождитесь публикации и откройте ссылку, показанную в разделе Pages.

Файл `museum-data.json` содержит фотографии и карту в формате base64, поэтому он большой. Не переименовывайте его без изменения имени в коде `index.html`.
